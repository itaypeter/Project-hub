# New App Onboarding

Paste this into Claude Code when starting a new app:

---

I have a new app to add to my Lapricode system. Please:

1. Create `context/<appname>.md` in the itaypeter/Project-hub repo
   with sections: What it is / Stack & Key Decisions / Ideas

2. Add it to the keyword table in CLAUDE.md (Step 2.5) so the
   autopilot loads its context automatically when tasks mention this app

3. Ask me these questions so you can fill in the context file:
   - What does this app do? (1-2 sentences)
   - Who is the user / what problem does it solve?
   - What's the tech stack? (or "not decided yet")
   - Any decisions already made I shouldn't second-guess?
   - Any ideas or features already in mind?

App name: [fill in]
