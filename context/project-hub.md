# Project Hub — Context & Ideas

## What it is
A React + Vite PWA that acts as a control panel for all Lapricode projects. The autopilot (Claude Code) reads project-log.json, picks up ideas, implements them, and reports back. The user sees live task status, outputs, and can add ideas from Apple Reminders.

## Stack & Key Decisions
- React + Vite, no TypeScript
- GitHub API for storage (no backend)
- Dark/light mode via data-theme on documentElement
- GitHub token stored in localStorage
- Autopilot runs on a schedule, reads this repo
